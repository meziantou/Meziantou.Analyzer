# MA0086 - Do not throw from a finalizer
<!-- sources -->
Source: [DoNotThrowFromFinalizerAnalyzer.cs](https://github.com/meziantou/Meziantou.Analyzer/blob/main/src/Meziantou.Analyzer/Rules/DoNotThrowFromFinalizerAnalyzer.cs)
<!-- sources -->

````csharp
class Test
{
    ~Test()
    {
        throw new Exception(); // non-compliant
    }
}
````

Throw expressions are also reported:

````csharp
class Test
{
    string _value;

    ~Test()
    {
        _value = _value ?? throw new Exception(); // non-compliant
    }
}
````

A lambda or a local function declared in a finalizer is not reported, as it is not executed by the finalizer:

````csharp
class Test
{
    ~Test()
    {
        Action action = () => throw new Exception(); // compliant
    }
}
````
