# MA0086 - Do not throw from a finalizer
<!-- sources -->
Source: [DoNotThrowFromFinalizerAnalyzer.cs](https://github.com/meziantou/Meziantou.Analyzer/blob/main/src/Meziantou.Analyzer/Rules/DoNotThrowFromFinalizerAnalyzer.cs)
<!-- sources -->

````csharp
class Test
{
    ~Test()
    {
        throw new Exception(); // non-compliant
    }
}
````

The rule does not report the `throw` statements that are only declared in the finalizer, such as the ones in the body of a lambda, an anonymous method or a local function, as they are not executed by the finalizer itself.

````csharp
class Test
{
    ~Test()
    {
        // compliant: creating the delegate does not throw
        Action action = () => throw new Exception();
    }
}
````
