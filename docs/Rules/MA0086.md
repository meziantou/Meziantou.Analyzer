# MA0086 - Do not throw from a finalizer
<!-- sources -->
Source: [DoNotThrowFromFinalizerAnalyzer.cs](https://github.com/meziantou/Meziantou.Analyzer/blob/main/src/Meziantou.Analyzer/Rules/DoNotThrowFromFinalizerAnalyzer.cs)
<!-- sources -->

````csharp
class Test
{
    ~Test()
    {
        throw new Exception(); // non-compliant
    }
}
````

The rule also reports the `throw` expressions:

````csharp
class Test
{
    string _value;

    ~Test()
    {
        _value = _value ?? throw new Exception(); // non-compliant
    }
}
````

The rule does not report the `throw` statements and expressions that are only declared in the finalizer, such as the ones in the body of a lambda, an anonymous method or a local function, as they are not executed by the finalizer itself.

````csharp
class Test
{
    ~Test()
    {
        // compliant: creating the delegate does not throw
        Action action = () => throw new Exception();
    }
}
````

The rule does not report the `throw` statements and expressions whose exception is always caught by a `try` statement declared in the finalizer, as the exception does not escape the finalizer. The exception is always caught when a `catch` clause without a filter handles its type.

````csharp
class Test
{
    ~Test()
    {
        try
        {
            // compliant: the exception is caught in the finalizer
            throw new InvalidOperationException();
        }
        catch (Exception)
        {
        }
    }
}
````
