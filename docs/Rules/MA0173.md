# MA0173 - Use LazyInitializer.EnsureInitialize
<!-- sources -->
Sources: [UseLazyInitializerEnsureInitializeAnalyzer.cs](https://github.com/meziantou/Meziantou.Analyzer/blob/main/src/Meziantou.Analyzer/Rules/UseLazyInitializerEnsureInitializeAnalyzer.cs), [UseLazyInitializerEnsureInitializeFixer.cs](https://github.com/meziantou/Meziantou.Analyzer/blob/main/src/Meziantou.Analyzer.CodeFixers/Rules/UseLazyInitializerEnsureInitializeFixer.cs)
<!-- sources -->

```c#
Interlocked.CompareExchange(ref _field, new Sample(), null); // non-compliant
LazyInitializer.EnsureInitialized(ref _field, () => new Sample()); // compliant
```

The rule is not reported when the return value of `Interlocked.CompareExchange` is used, as `Interlocked.CompareExchange` returns the previous value of the target whereas `LazyInitializer.EnsureInitialized` returns the initialized value.

```c#
// compliant as the return value is used to detect which caller initialized the value
if (Interlocked.CompareExchange(ref _field, new Sample(), null) is null)
{
    // ...
}
```
