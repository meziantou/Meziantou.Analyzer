# MA0076 - Do not use implicit culture-sensitive ToString in interpolated strings

Sources: [DoNotUseImplicitCultureSensitiveToStringAnalyzer.cs](https://github.com/meziantou/Meziantou.Analyzer/blob/main/src/Meziantou.Analyzer/Rules/DoNotUseImplicitCultureSensitiveToStringAnalyzer.cs), [DoNotUseImplicitCultureSensitiveToStringInterpolationFixer.cs](https://github.com/meziantou/Meziantou.Analyzer/blob/main/src/Meziantou.Analyzer.CodeFixers/Rules/DoNotUseImplicitCultureSensitiveToStringInterpolationFixer.cs)
<!-- sources -->

````csharp
_ = $"abc{-1}"; // non-compliant as the result depends on the current culture

_ = FormattableString.Invariant($"abc{-1}"); // compliant but will generate MA0111
_ = string.Create(CultureInfo.InvariantCulture, $"abc{-1}"); // compliant
FormattableString str = $"abc{-1}"; // compliant
````

The analyzer classifies values as culture-sensitive, culture-insensitive, or maybe culture-sensitive. It reports culture-sensitive values, including types implementing `IFormattable` or `ISpanFormattable` and types with a provider-aware `ToString` overload. Known culture-invariant types, invariant formats and values, sealed types that do not support culture-aware formatting, and types marked with `CultureInsensitiveTypeAttribute` are culture-insensitive. Values typed as `object`, an interface, a type parameter, or a non-sealed class are maybe culture-sensitive because their runtime type can format differently. They are not reported by default; set `MA0076.report_maybe_culture_sensitive` to `true` to report them.

## Configuration

````
# Exclude ToString methods from analysis
MA0076.exclude_tostring_methods=true

# Report Nullable<T>.ToString when T is culture-sensitive
MA0076.consider_nullable_types=true

# Report values that may be culture-sensitive based on their runtime type
MA0076.report_maybe_culture_sensitive=true
````

You can also annotate a type with `[Meziantou.Analyzer.Annotations.CultureInsensitiveTypeAttribute]` to disable the rule for this type. See [CultureInsensitiveTypeAttribute](../CultureInsensitiveTypeAttribute.md) for details and [Meziantou.Analyzer.Annotations README](https://github.com/meziantou/Meziantou.Analyzer/blob/main/src/Meziantou.Analyzer.Annotations/README.md) for installation options.
