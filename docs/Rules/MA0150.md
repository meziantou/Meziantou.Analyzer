# MA0150 - Do not call ToString() when the type falls back to object.ToString()
<!-- sources -->
Source: [DoNotUseToStringIfObjectAnalyzer.cs](https://github.com/meziantou/Meziantou.Analyzer/blob/main/src/Meziantou.Analyzer/Rules/DoNotUseToStringIfObjectAnalyzer.cs)
<!-- sources -->

Report when `ToString` is called on an instance of a type that doesn't override `ToString`:

```c#
object o = ...;
o.ToString(); // compliant as ToString may be overridden

var o = new Foo();
o.ToString(); // Non-compliant as Foo doesn't override ToString and is sealed

sealed class Foo {}
```

A `closed` type (C# 15) cannot be inherited from outside its containing module, so the whole set of possible runtime types is known.
The diagnostic is reported when no type of the hierarchy overrides `ToString`:

```c#
Shape shape = ...;
shape.ToString(); // Non-compliant as no type of the closed hierarchy overrides ToString

closed class Shape;
sealed class Circle : Shape;
sealed class Square : Shape;
```

```c#
Shape shape = ...;
shape.ToString(); // compliant as Square overrides ToString

closed class Shape;
sealed class Circle : Shape;
sealed class Square : Shape { public override string ToString() => "square"; }
```
