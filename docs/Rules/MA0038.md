# MA0038 - Make method static (deprecated, use CA1822 instead)

> **Warning**
> This rule is deprecated and will be removed in the future. It is recommended to use [CA1822](https://learn.microsoft.com/en-us/dotnet/fundamentals/code-analysis/quality-rules/ca1822?WT.mc_id=DT-MVP-5003978) instead.

If the method only uses static or const members, you should consider making the method static.

The rule does not report the members that are accessed through an instance other than `this` or `base` (`instance.Method()`, `instance?.Method()`), or in an object initializer or a property pattern, as a static member cannot be accessed this way. The code fix replaces `this.Method()` and `base.Method()` with `Method()`.

The rule does not report the members that use a parameter of the primary constructor, which is captured by the instance, nor the members that the compiler binds by name on an instance (`GetEnumerator`, `MoveNext`, `Current`, `Dispose`, `DisposeAsync`, `GetAwaiter`, `GetResult`, `IsCompleted`, `Deconstruct`, `Add`, `GetPinnableReference`, `Slice`, `Length`, `Count`, ...). The code fix removes the `readonly` modifier of the members of a struct, as a static member cannot be `readonly`.
