# MA0168 - Use readonly struct for in or ref readonly parameter
<!-- sources -->
Source: [UseReadOnlyStructForRefReadOnlyParametersAnalyzer.cs](https://github.com/meziantou/Meziantou.Analyzer/blob/main/src/Meziantou.Analyzer/Rules/UseReadOnlyStructForRefReadOnlyParametersAnalyzer.cs)
<!-- sources -->

```c#
void A(in Foo p) { } // not-compliant as Foo is not readonly

struct Foo { }
```

```c#
void A(in Foo p) { } // ok

readonly struct Foo { }
```

The rule only reports the structs declared in the current project, as the other types cannot be changed. Enums are not reported, as they cannot be declared as `readonly struct`.

```c#
void A(in DayOfWeek p) { } // ok, enums cannot be readonly structs
void B(in int? p) { } // ok, Nullable<T> is not declared in the current project
```
