# MA0168 - Use readonly struct for in or ref readonly parameter
<!-- sources -->
Source: [UseReadOnlyStructForRefReadOnlyParametersAnalyzer.cs](https://github.com/meziantou/Meziantou.Analyzer/blob/main/src/Meziantou.Analyzer/Rules/UseReadOnlyStructForRefReadOnlyParametersAnalyzer.cs)
<!-- sources -->

```c#
void A(in Foo p) { } // not-compliant as Foo is not readonly

struct Foo { }
```

```c#
void A(in Foo p) { } // ok

readonly struct Foo { }
```

Enums are not reported, as they cannot be declared as `readonly struct`. The non-readonly structs declared in other assemblies are reported: they cannot be made readonly, but the parameter can be passed by value instead to avoid the defensive copies.

```c#
void A(in DayOfWeek p) { } // ok, enums cannot be readonly structs
void B(in List<int>.Enumerator p) { } // not-compliant, List<int>.Enumerator is not readonly
```
