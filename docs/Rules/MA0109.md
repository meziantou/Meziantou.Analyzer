# MA0109 - Consider adding an overload with a Span\<T\> or Memory\<T\>
<!-- sources -->
Source: [AddOverloadWithSpanOrMemoryAnalyzer.cs](https://github.com/meziantou/Meziantou.Analyzer/blob/main/src/Meziantou.Analyzer/Rules/AddOverloadWithSpanOrMemoryAnalyzer.cs)
<!-- sources -->

````c#
void A(string[] a) { } // ok as there is an overload with Span
void A(System.ReadOnlySpan<string> a) { }
````

````c#
void A(string[] a) { } // report diagnostic
````

The type parameters of generic methods are matched by position:

````c#
void A<T>(T[] a) { } // ok as there is an overload with Span
void A<TItem>(System.ReadOnlySpan<TItem> a) { }
````

The rule does not report a diagnostic for the program entry point (`Main(string[] args)`), as its signature is mandated by the runtime.
