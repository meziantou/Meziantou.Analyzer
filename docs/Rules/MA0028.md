# MA0028 - Optimize StringBuilder usage
<!-- sources -->
Sources: [OptimizeStringBuilderUsageAnalyzer.cs](https://github.com/meziantou/Meziantou.Analyzer/blob/main/src/Meziantou.Analyzer/Rules/OptimizeStringBuilderUsageAnalyzer.cs), [OptimizeStringBuilderUsageFixer.cs](https://github.com/meziantou/Meziantou.Analyzer/blob/main/src/Meziantou.Analyzer.CodeFixers/Rules/OptimizeStringBuilderUsageFixer.cs)
<!-- sources -->

```csharp
new StringBuilder().Append($"a{10}");
new StringBuilder().Append("a" + 10);

// Should be
new StringBuilder().Append("a").Append(10);
```

The concatenation of constant strings and chars (e.g. `" " + ConstChar + " "`) is not reported, as the compiler merges it into a single string.

```csharp
new StringBuilder().Append("a");

// Should be
new StringBuilder().Append('a');
```

`AppendLine("a")` is not reported, as `AppendLine` has no overload that takes a `char`.

```csharp
new StringBuilder().Append(10.ToString());

// Should be
new StringBuilder().Append(10);
```

`char[].ToString()` is not reported, as it returns `"System.Char[]"`, whereas `Append(char[])` appends the characters of the array.

```csharp
sb.Append("");

// Should be removed
```

The code fix replaces the call with its receiver, such as `sb.Append("").AppendLine()` with `sb.AppendLine()`. When the result of the call is not used and the receiver is not a method call, the code fix removes the statement, so it is only offered when the receiver is a local, a parameter, `this`, or a field. The code fix is not offered when another argument, such as the index of `Insert(index, "")`, may have side effects, as it would not be evaluated anymore.

```csharp
new StringBuilder().AppendFormat("no placeholders", arg);
new StringBuilder().AppendFormat("{{escaped braces}}", arg);

// Should be
new StringBuilder().Append("no placeholders");
new StringBuilder().Append("{escaped braces}");
```

The rule does not report `AppendFormat` when the format string is invalid (e.g. `"{text}"` or `"}"`), as `AppendFormat` throws a `FormatException` for such format strings.

```csharp
new StringBuilder().Append(string.Join(", ", values));

// Should be
new StringBuilder().AppendJoin(", ", values);
```

`string.Join(separator, value, startIndex, count)` is not reported, as `AppendJoin` has no overload that takes a range.
