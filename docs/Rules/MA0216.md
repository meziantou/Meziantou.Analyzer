# MA0216 - Remove unnecessary closed modifier
<!-- sources -->
Source: [RemoveUnnecessaryClosedModifierAnalyzer.cs](https://github.com/meziantou/Meziantou.Analyzer/blob/main/src/Meziantou.Analyzer/Rules/RemoveUnnecessaryClosedModifierAnalyzer.cs)
<!-- sources -->

A `closed` type is implicitly abstract, so it can only be instantiated through one of its derived types. When no type derives from it, the type cannot be used at all.

The rule is only reported when the compiler can determine the complete list of derived types.

There is no code fix, as every way to resolve the diagnostic changes the meaning of the code: removing the modifier makes the type instantiable and inheritable, replacing it with `sealed` makes it instantiable, replacing it with `abstract` allows any type to derive from it, and adding a derived type completes the hierarchy.

## Non-compliant code

````csharp
closed class Sample
{
}
````

## Compliant code

````csharp
closed class Sample
{
}

class Derived : Sample
{
}
````
