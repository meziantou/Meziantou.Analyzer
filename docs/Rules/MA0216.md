# MA0216 - Remove unnecessary closed modifier
<!-- sources -->
Sources: [RemoveUnnecessaryClosedModifierAnalyzer.cs](https://github.com/meziantou/Meziantou.Analyzer/blob/main/src/Meziantou.Analyzer/Rules/RemoveUnnecessaryClosedModifierAnalyzer.cs), [RemoveUnnecessaryClosedModifierFixer.cs](https://github.com/meziantou/Meziantou.Analyzer/blob/main/src/Meziantou.Analyzer.CodeFixers/Rules/RemoveUnnecessaryClosedModifierFixer.cs)
<!-- sources -->

A `closed` type is implicitly abstract, so it can only be instantiated through one of its derived types. When no type derives from it, the type cannot be used at all and the `closed` modifier should be removed.

The rule is only reported when the compiler can determine the complete list of derived types.

Two code fixes are available:

- Remove the `closed` modifier, which makes the type instantiable and inheritable
- Replace the `closed` modifier with `sealed`, which keeps the type non-inheritable

When the type cannot become a concrete type, because it has an abstract member that is not overridden, the only available code fix replaces the `closed` modifier with `abstract`.

## Non-compliant code

````csharp
closed class Sample
{
}
````

## Compliant code

````csharp
class Sample
{
}
````

````csharp
sealed class Sample
{
}
````

````csharp
closed class Sample
{
}

class Derived : Sample
{
}
````
