# MA0213 - Simplify negated boolean expression
<!-- sources -->
Sources: [SimplifyNegatedBooleanExpressionAnalyzer.cs](https://github.com/meziantou/Meziantou.Analyzer/blob/main/src/Meziantou.Analyzer/Rules/SimplifyNegatedBooleanExpressionAnalyzer.cs), [SimplifyNegatedBooleanExpressionFixer.cs](https://github.com/meziantou/Meziantou.Analyzer/blob/main/src/Meziantou.Analyzer.CodeFixers/Rules/SimplifyNegatedBooleanExpressionFixer.cs)
<!-- sources -->

This rule reports negated boolean expressions that can be simplified by applying [De Morgan's laws](https://en.wikipedia.org/wiki/De_Morgan%27s_laws).

The rule does not report plain negated groups such as `!(a && b)`, because the expanded form is not consistently easier to read.

This rule is disabled by default.

## Non-compliant code

````csharp
if (!(key == 'y' && !IsEditable(target)))
{
}
````

## Compliant code

````csharp
if (key != 'y' || IsEditable(target))
{
}
````
