# MA0052 - Replace constant Enum.ToString with nameof
<!-- sources -->
Sources: [ReplaceEnumToStringWithNameofAnalyzer.cs](https://github.com/meziantou/Meziantou.Analyzer/blob/main/src/Meziantou.Analyzer/Rules/ReplaceEnumToStringWithNameofAnalyzer.cs), [ReplaceEnumToStringWithNameofFixer.cs](https://github.com/meziantou/Meziantou.Analyzer/blob/main/src/Meziantou.Analyzer.CodeFixers/Rules/ReplaceEnumToStringWithNameofFixer.cs)
<!-- sources -->

You should use `nameof` instead of calling `ToString` on a constant enumeration value. This is primarily for performance reasons.

````csharp
public enum Color
{
    Blue,
    Red,
    Yellow,
}

void Sample()
{
    _ = Color.Blue.ToString(); // non compliant
    _ = nameof(Color.Blue); // compliant
}
````

When several members of the enumeration share the same value, `ToString` formats the value, so it may return the name of another member than the one used in the source code, while `nameof` always returns the name used in the source code. In this case, the code fix uses the first declared member, which is the name returned by the .NET runtime, and provides one alternative code fix per other member sharing the value.

````csharp
public enum Color
{
    Red = 0,
    Other = 0,
}

void Sample()
{
    _ = Color.Other.ToString(); // non compliant, returns "Red"
    _ = nameof(Color.Red); // compliant (default code fix)
}
````
