# MA0051 - Method is too long
<!-- sources -->
Source: [MethodShouldNotBeTooLongAnalyzer.cs](https://github.com/meziantou/Meziantou.Analyzer/blob/main/src/Meziantou.Analyzer/Rules/MethodShouldNotBeTooLongAnalyzer.cs)
<!-- sources -->

Long methods are harder to understand. You should refactor them when possible.

The rule reports methods, local functions, constructors, destructors, operators, conversion operators, and the accessors and expression bodies of properties, indexers, and events.

You can configure the rule using an `.editorconfig` file:

````editorconfig
MA0051.maximum_lines_per_method = 60
MA0051.maximum_statements_per_method = 40
MA0051.skip_local_functions = false # skip local functions when counting statements
````
