## Description

The rule reports the syntax nodes configured in the `.editorconfig` file. This lets a project ban a language construct, such as `goto`, `lock`, primary constructors, or nested conditional expressions, without writing a dedicated analyzer.

The syntax to ban is configured with a list of syntax kinds, with an XPath query, or with both. A node matched by both options is reported once.

The kinds are the names of the members of the [`Microsoft.CodeAnalysis.CSharp.SyntaxKind`](https://learn.microsoft.com/en-us/dotnet/api/microsoft.codeanalysis.csharp.syntaxkind) enumeration. Only the kinds of syntax nodes are supported, not the kinds of tokens or trivia.

To find the kind of a construct, you can use:

- [`SyntaxKind.cs`](https://github.com/dotnet/roslyn/blob/main/src/Compilers/CSharp/Portable/Syntax/SyntaxKind.cs), the list of all the kinds in the Roslyn source code
- [Roslyn Quoter](https://roslynquoter.azurewebsites.net/), which shows the syntax factory calls that create a snippet, including the kind of each node
- [Razor Lab](https://lab.razor.fyi/#csharp), which shows the syntax tree of a C# snippet
- [SharpLab](https://sharplab.io) (Syntax Tree view)
- The Syntax Visualizer of Visual Studio

When a node of a banned kind contains another node of a banned kind, both nodes are reported.

## Configuration

This rule is disabled by default, and it reports nothing until the syntax to ban is configured. To enable it, add the following to your `.editorconfig` file:

````editorconfig
[*.cs]
dotnet_diagnostic.MA0240.severity = warning

# The kinds of the syntax nodes to report, separated by commas or whitespace
MA0240.syntax_kinds = GotoStatement, LockStatement

# An XPath query selecting the syntax to report
MA0240.query = //ClassDeclaration/ParameterList | //ConditionalExpression//ConditionalExpression
````

Do not use `;` or `#` in the values, as they start a comment in `.editorconfig` files.

### Syntax kinds

`MA0240.syntax_kinds` is a list of kinds separated by commas or whitespace. The names are not case-sensitive. The names that are not a member of `SyntaxKind` in the version of Roslyn used by the compiler are ignored.

### XPath query

`MA0240.query` is an [XPath 1.0](https://www.w3.org/TR/xpath-10/) query evaluated on each file, which is exposed as an XML document:

- Each syntax node is an element named after its kind, such as `ClassDeclaration` or `ParameterList`. The children of an element are the child nodes of the syntax node.
- The tokens of a node are the attributes of its element, named after the property of the node that returns them, such as `Identifier`, `Keyword`, or `Modifiers`. The value of an attribute is the text of the token. When the property returns several tokens, such as `Modifiers`, the value is the text of the tokens separated by a space. Missing tokens are not exposed.

The rule reports each element or attribute selected by the query. When the query selects an attribute, the diagnostic is reported on the tokens of the attribute. Use the `|` operator to combine several queries.

| Query | Reported syntax |
|-------|-----------------|
| `//ClassDeclaration/ParameterList` | The parameter list of the primary constructors of classes |
| `//ClassDeclaration[ParameterList]` | The classes that declare a primary constructor |
| `//ClassDeclaration/ParameterList \| //StructDeclaration/ParameterList` | The parameter list of the primary constructors of classes and structs |
| `//ConditionalExpression//ConditionalExpression` | The conditional expressions nested in another conditional expression |
| `//MethodDeclaration[@Identifier='Execute']` | The methods named `Execute` |
| `//MethodDeclaration/@Modifiers[contains(., 'async')]` | The modifiers of the `async` methods |
| `//ReturnStatement[ancestor::ConstructorDeclaration]` | The `return` statements in constructors |
| `//MethodDeclaration[count(ParameterList/Parameter) > 5]/@Identifier` | The name of the methods with more than 5 parameters |
| `//*[count(ParameterList/Parameter) > 5]/@Identifier` | The name of the methods, constructors, local functions, delegates, and types with a primary constructor that have more than 5 parameters |

Records use `ParameterList` for their positional parameters too, so `//RecordDeclaration/ParameterList` selects the positional parameters of records.

When the query is not a valid XPath query or does not return a node-set, the rule reports a diagnostic with no location that describes the error.

## Example

With `MA0240.syntax_kinds = GotoStatement, ConditionalExpression`:

````c#
class Sample
{
    int Test(bool a, bool b)
    {
        goto end; // ❌ GotoStatement

    end:
        return a ? 1 : 2; // ❌ ConditionalExpression
    }
}
````

With `MA0240.query = //ClassDeclaration/ParameterList`:

````c#
class Sample(int value) // ❌ ClassDeclaration has a primary constructor
{
}

class Other // ✅ No primary constructor
{
    public Other(int value) { }
}
````
