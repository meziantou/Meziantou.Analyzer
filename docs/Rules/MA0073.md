# MA0073 - Avoid comparison with bool constant
<!-- sources -->
Sources: [AvoidComparisonWithBoolConstantAnalyzer.cs](https://github.com/meziantou/Meziantou.Analyzer/blob/main/src/Meziantou.Analyzer/Rules/AvoidComparisonWithBoolConstantAnalyzer.cs), [AvoidComparisonWithBoolConstantFixer.cs](https://github.com/meziantou/Meziantou.Analyzer/blob/main/src/Meziantou.Analyzer.CodeFixers/Rules/AvoidComparisonWithBoolConstantFixer.cs)
<!-- sources -->

## Non-compliant code

```csharp
const bool MyConstant = false;
bool value = GetSomeValue();

if (value == MyConstant)
{
}
```

## Compliant code

```csharp
const bool MyConstant = false;
bool value = GetSomeValue();

if (!value)
{
}
```

The rule only reports the built-in `bool` equality operators. It does not report the comparisons that use a user-defined operator, such as `operator ==(MyType, bool)`, as removing the constant would change the meaning of the code.
