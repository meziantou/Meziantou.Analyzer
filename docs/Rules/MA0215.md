# MA0215 - Return the task instead of awaiting it
<!-- sources -->
Sources: [ReturnTaskInsteadOfAwaitingItAnalyzer.cs](https://github.com/meziantou/Meziantou.Analyzer/blob/main/src/Meziantou.Analyzer/Rules/ReturnTaskInsteadOfAwaitingItAnalyzer.cs), [ReturnTaskInsteadOfAwaitingItFixer.cs](https://github.com/meziantou/Meziantou.Analyzer/blob/main/src/Meziantou.Analyzer.CodeFixers/Rules/ReturnTaskInsteadOfAwaitingItFixer.cs)
<!-- sources -->

When a method does nothing but await a single task and return its result, the `async`/`await` machinery is unnecessary. Returning the task directly removes the state machine, saving an allocation and a few stack frames.

This rule is the opposite of [MA0214](MA0214.md) and is disabled by default. Enable only one of the two rules depending on the style you prefer.

````c#
async Task Sample() => await DoSomethingAsync(); // non-compliant

Task Sample() => DoSomethingAsync(); // compliant
````

To preserve the original behavior, the rule only reports when it is safe to remove the `await`: the awaited task must be the whole body of the method (`return await X;` or `await X;`), so it is never reported inside `try`/`catch`/`finally`, `using`, `lock`, or `fixed` blocks. A trailing `ConfigureAwait` call is removed by the code fix.
