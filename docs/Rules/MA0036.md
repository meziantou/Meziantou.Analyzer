# MA0036 - Make class static
<!-- sources -->
Sources: [MakeClassStaticAnalyzer.cs](https://github.com/meziantou/Meziantou.Analyzer/blob/main/src/Meziantou.Analyzer/Rules/MakeClassStaticAnalyzer.cs), [MakeClassStaticFixer.cs](https://github.com/meziantou/Meziantou.Analyzer/blob/main/src/Meziantou.Analyzer.CodeFixers/Rules/MakeClassStaticFixer.cs)
<!-- sources -->

If the class only contains static or const members, you should consider making the class static.

The rule does not report the classes that are used in a way that is not allowed for a static class: instantiated, inherited, used as a type argument, as the type of a field, property, event, parameter, return value or variable, as a generic constraint, as an array element type, in a cast, or in a type pattern.
