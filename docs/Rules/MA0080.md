# MA0080 - Use a cancellation token using .WithCancellation()
<!-- sources -->
Source: [UseAnOverloadThatHasCancellationTokenAnalyzer.cs](https://github.com/meziantou/Meziantou.Analyzer/blob/main/src/Meziantou.Analyzer/Rules/UseAnOverloadThatHasCancellationTokenAnalyzer.cs)
<!-- sources -->

````c#
IAsyncEnumeration<string> enumerable;
await foreach (var item in enumerable) // not compliant
{
}

await foreach (var item in enumerable.WithCancellation(cancellationToken)) // compliant
{
}
````

## Exclude a method from this rule

The method returning the enumerable can be marked as valid to call without a `CancellationToken` using [`ExcludeFromCancellationTokenAnalysisAttribute`](https://github.com/meziantou/Meziantou.Analyzer/blob/main/src/Meziantou.Analyzer.Annotations/README.md) from the `Meziantou.Analyzer.Annotations` package.

````c#
[Meziantou.Analyzer.Annotations.ExcludeFromCancellationTokenAnalysis]
static IAsyncEnumerable<string> Enumerate() => throw null;

await foreach (var item in Enumerate()) // compliant
{
}
````

The methods of another assembly can be excluded at the assembly level, using their XML documentation id or their containing type and name:

````c#
[assembly: Meziantou.Analyzer.Annotations.ExcludeFromCancellationTokenAnalysis("M:Sample.Enumerate")]
[assembly: Meziantou.Analyzer.Annotations.ExcludeFromCancellationTokenAnalysis(typeof(Sample), "Enumerate")]
````
