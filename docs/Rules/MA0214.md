# MA0214 - Use 'await' instead of returning the task
<!-- sources -->
Sources: [UseAwaitInsteadOfReturningTaskAnalyzer.cs](https://github.com/meziantou/Meziantou.Analyzer/blob/main/src/Meziantou.Analyzer/Rules/UseAwaitInsteadOfReturningTaskAnalyzer.cs), [UseAwaitInsteadOfReturningTaskFixer.cs](https://github.com/meziantou/Meziantou.Analyzer/blob/main/src/Meziantou.Analyzer.CodeFixers/Rules/UseAwaitInsteadOfReturningTaskFixer.cs)
<!-- sources -->

Prefer awaiting the task instead of returning it directly. Awaiting the task keeps the method in the async state machine, which produces more accurate stack traces and ensures exceptions are observed inside the method.

This rule is the opposite of [MA0215](MA0215.md) and is disabled by default. Enable only one of the two rules depending on the style you prefer.

````c#
Task<int> Sample() => GetValueAsync(); // non-compliant

async Task<int> Sample() => await GetValueAsync(); // compliant
````

The rule only reports methods, local functions, and lambdas whose whole body is a single task-returning `return` statement or expression body.
